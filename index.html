Client-side image analysis using multiple methods

Available Methods & How They Work

1. NSFW.js (Recommended)

Uses a pre-trained TensorFlow.js model specifically designed for NSFW content detection. Most accurate method.

Pros: High accuracy, specifically trained for this task

Cons: Larger model size (~1MB), requires internet for initial download

2. Skin Tone Detection

Analyzes pixel colors to detect skin tones and calculates percentage of skin-colored pixels.

Pros: Fast, lightweight, no external dependencies

Cons: Can trigger false positives (beaches, portraits), limited accuracy

3. Color Analysis

Examines color distribution, saturation, and specific color patterns often found in mature content.

Pros: Fast, catches certain visual patterns

Cons: High false positive rate, not reliable alone

4. Edge Detection

Uses computer vision to detect edges and shapes that might indicate mature content.

Pros: Can detect certain geometric patterns

Cons: Very basic, high false positive rate
